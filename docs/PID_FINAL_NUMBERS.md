## 4. 定案的流程

| 階段 | 做法 | 設定 |
|---|---|---|
| 逐手特徵 | 預訓練的人類棋力網路的主幹向量（全盤 64 維＋落點 64 維）；部分家族把其中一半換成有監督的投影 | 每局前 256 手 |
| 序列網路 | Transformer 逐手讀一整盤棋，輸出這位棋手的單位向量；另有兩個 9×9 的棋形視窗（自己的落點周圍、對手上一手周圍） | 384×8 層為主，四個家族 512×10 層 |
| 訓練資料 | 競賽訓練玩家（含 fold 0）＋外部公開棋譜帳號 17.6 萬個；照局數抽樣；對稱增強、隨機遮手 | 3～5.5 萬步 |
| 題池微調 | 每個網路對該題庫候選人的參考棋微調（不碰題目棋、兩個題庫不混用） | 50 步 |
| 逐手成分 | 題目各局向量的和，對候選人各局向量的和，取餘弦；逐列標準化後 136 個網路加權平均 | 見第 5 節 |
| 融合 | 逐手成分加上 8 個較早的成分（開局、方向、局部、風格、讓子、每局嵌入）線性加權 | 權重 `w11c`（§2.233） |
| 多局題配對 | 2／3／5 局題的擁有者互不重複：第一名用軟性一對一配對，第 2–5 名扣掉「搶手程度」 | λ＝2、τ＝0.5 |
| 1 局題先驗 | 1 局題的擁有者幾乎不會是 3 局題的擁有者 | w＝0.05、T＝1.6 |
| 原題池 | 800 列沿用 11-10 的舊流程（Public 原題池 1.0000） | 未再更動 |

- 預訓練網路：KataGo 的人類棋力模型，用來抽每一手的主幹特徵。
- fold 0：使用者 2026-11-18 同意把 fold 0 的訓練玩家用於序列網路的訓練。
