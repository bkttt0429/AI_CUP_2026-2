# Identity versus variation between observations

Freeze these tests before observing any outcomes. The accepted model is v2fin4_f. Prior global PLDA, cohort normalization, nearest-game scoring and tactical timing studies are documented in the project. This study uses no move-specific Go feature.

1. **Actual finalist persistence.** In each pool and split, use one designated single-game discovery query per player (slot zero). If its true player A ranks second to B among all 600, freeze the pair. Hash-sort directed nominations and greedily retain vertex-disjoint pairs so one player cannot supply outcomes to multiple primary pairs. Keep the same seven references and the original model, then compare A against that very same B on A's other two independent games. Also evaluate B's two independent games, and how often A wins the full roster or the same B still ranks first. This is a diagnostic using labelled discovery cases. Primary split 1. Repeat split 3 separately, since physical games overlap. Report count and paired bootstrap by nominated pair within pool. Report the pooled-query result only as a known-owner diagnostic.
2. **Crossed independent repetitions.** In the training corpus select up to 600 fold-2 players with 24 eligible physically distinct games in the frozen out-of-fold sequence embedding. Exclude IDs and exact full move histories recorded in the earlier calibration/candidate, reference-policy, local-choice and nearby-replication studies. Use hash order for players and games; at least 250 eligible players required. For each player reserve seven discovery references, one unused discovery query, two *disjoint* sets of seven evaluation references, and two distinct evaluation queries. Using discovery reference means only, form hard pairs among mutual five-nearest neighbours, greedy highest cosine, disjoint players. Score both identities under every two-by-two combination of references and query observations with a fixed cosine comparator. Compare paired sign-flip rates when only the query changes versus only the references, with pair bootstrap; primary contrast is query minus reference flip rate. Estimate gains from doubling reference size versus pooling two queries on the *same fixed pair*, and signed cross-split centroid inner product versus the corresponding same-split squared distance. Use pooled queries only diagnostically. The frozen encoder and pairwise outcome here differ from the strong official ensemble and full-roster score.
3. **A pair-specific observation-noise model.** Use the existing 128 distinct sequence members of the accepted system with their actual multiplicities, concatenating weighted unit game embeddings implicitly through their Gram matrix. Official candidates only, restricted to a pool at a time. Keep original ensemble top two. For each candidate pair, start with its unit centroid-difference direction and midpoint. Estimate within-person scatter from the seven references of each finalist after separately centering each player. Downweight high-scatter directions with a ridge Fisher discriminant. In units of the unscaled 14-row residual Gram, the ridge is trace divided by 12, fixed. Normalize the resulting direction to unit norm. Correction is the Fisher margin minus the isotropic margin, both relative to the same midpoint. The placebo uses within-person scatter of two fixed other players from the same respective owner folds. Marginal comparisons are isotropic-only and Fisher-only with identical scalar-fit capacity. Train only the nonnegative scale of each correction after freezing calibration of the baseline gap; use the held-out discovery slot, only true-in-top-two learning cases, excluding the folds of both evaluation finalists. Apply by finalist IDs and observed query without its truth. On all 2,400 evaluation games measure the primary residual vs baseline, versus placebo, rescued/broken winners and owner-cluster 95% CIs (5,000 draws stratified by pool). Require at least +0.002 in mean single-game rank score with lower bound above zero, plus a positive lower bound against placebo to attribute a gain. Split 1 primary, split 3 repeat without tuning. Only a passing single-game study merits the project's larger promotion tests on 1/2/3-game mixes. No submission.
4. Run Slurm tests of the ridge formula against direct linear algebra, candidate-order symmetry, no effect with zero scatter, crossed manipulations and disjoint pairing. Recompute outcomes from retained row-level decisions. All inference is conditional on frozen models and enrolled cohorts. Follow the existing 6 GPU-hour cumulative limit; store small outputs in the research worktree and use scratch RAM for pooled Gram matrices.

The experiment design adapts template-specific classifiers in [Crosswhite et al.](https://robots.ox.ac.uk/~vgg/publications/2017/Crosswhite17/), enrolled-speaker covariance estimation in [Madikeri et al.](https://publications.idiap.ch/attachments/reports/2016/Madikeri_Idiap-RR-05-2017.pdf), and the independently replicated distance principle in [Walther et al.](https://pubmed.ncbi.nlm.nih.gov/26707889/). Our distance uses the frozen embedding's Euclidean metric. The published results apply to their original tasks.
