# Replicating temporal identity information independently of a reranking gain

Registered after seeing the first evaluation on splits 1 and 3. The chronological template identified the true finalist in 59.82% of cases and the shuffled template in 48.15%, with a zero-crossing competition effect. Correct original nominations greatly outnumber mistakes. This follow-up tests whether the standalone identity comparison reproduces. Keep both probes, template construction and control fixed. Do not fit any weights or advance the failed ranking rule.

## New query appearances with ground truth among the nominees

Use the certified candidate-only finalist and ownership archives for splits 0 and 2. Exclude any game from any query slot (including fitting) of splits 1 or 3, then deduplicate eligible query keys across 0 and 2, retaining split 0 first, independent of rank. Match the recovered seven-reference rows, query keys, owners and finalist order to the archived source. Report the rates of choosing the right player in two strata (true first and true second), their equal-weight balanced mean and paired chronological minus shuffled contrasts. Bootstrap 1,200 owners within pool, carrying both splits together. These games have already served as references and the splits were used for other, earlier methods.

## Same pair with one new game from each player

On split 0 build a separate reference-only similarity roster from the unit seven-game centroids of each probe, averaging their two cosine matrices. Select disjoint mutual top-five neighbors greedily in descending similarity with a deterministic owner-index tie break. For each selected pair and each player choose their first of the three split-0 holdout slots that was never a query on split 1 or 3. Both players must supply one. Ignore the committee's prediction when selecting these games. Compute the two template decisions with the same pair of candidate reference panels; award half for exact ties. With one query from each player, always choosing one person gives exactly 50%. Report accuracy, paired chronological minus shuffled accuracy, and the fraction of pairs with both/neither correct. Bootstrap disjoint player pairs within pool. Prespecified sensitivity keeps query pairs of identical subject colour and observed length difference at most 16 plies (capped at the model's 256). Report the sample size. This diagnostic addresses repeated personal information and cannot establish a full-roster ranking gain. Treat the diagnostic as replicated if its accuracy interval and its advantage over the shuffled control both clear chance and zero, respectively. The existing adoption threshold remains separate.
