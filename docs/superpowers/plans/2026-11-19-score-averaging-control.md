# How many two-game recoveries require the native joint readout?

Registered after finding 159 accepted joint wins among 565 both-wrong single-game pairs on splits 4/5. Freeze the accepted full v2fin4_f composition and all label-based subsets from the preceding experiment. Use only the same two held-out games in each of those 2,400 two-game queries.

Compare the native joint scores with the equally weighted arithmetic average of the two complete single-game fusion score vectors, on all 600 candidates, without fitting, external labels, temperature or filtering. Make additional native two-game queries with each single game literally duplicated. These compare two input slots with one unique observation and two slots with two observations. Verify the first single, second single and native real-pair ranks and original winners against the frozen decision records. Report duplicate-versus-single ranking changes and absolute score differences. Report top-1 and competition score differences, native-only and average-only rescues, and overlap among the 159. Bootstrap by query owner in each pool, retaining both seeds.

For pairs where both singles are wrong and point to different people, use the simple averaged score to count which beat both original wrong nominees yet still lose to a third person. For identical wrong nominees the positive average of two score vectors cannot strictly elevate truth over that common nominee if both original margins favor it. The native model includes nonlinear aggregation, so its empirical zero requires separate interpretation. These are mechanistic controls on genuine multi-game input. This follow-up does not change the single-game ranking or competition gate.
