# Local conditional choice experiment

**Goal** Measure whether a candidate's reference games predict their decisions better when retrieval uses the local shape around the opponent's last move. The specification is in [the design](../specs/2026-11-18-local-choice-signal-design.md). Use the existing research worktree and production Slurm.

**Data** Reuse the prior 200 training and 50 development owners. Select 100 fresh fold 4 owners with ten games by a new deterministic hash. Exclude owners from both previous study manifests and reject physical-game overlaps with all previous manifests when selecting fresh games. Seven reference games, three held-out games and 32 distinct positions evenly spaced over the available own moves in the first 256 plies. Count available owners, rejected games, and ranks. No competition question games. The fixed humanv0 backbone has the prior manifest's checksum. Its pretraining overlap with the players is unknown.

**Model** Preserve the frozen full spatial trunk at every point and the separate pass indicator. For every proposed move, encode the full 9×9 patch as occupancy averages over the 15 sets of offsets equivalent under rotations and reflections, for friendly stones, enemy stones and off-board points. Read the same descriptor at the previous point as well as the relative distances. Include products between the two descriptors and between the previous shape and closeness to the proposed move. This chosen small model loses angular structure within each set. It tests explicit local terms without retraining the backbone. A shared linear projection of the action basis gives both the proposed-action embedding and the observed-minus-policy-expected reference embedding. Allow a null attention slot and normalize over legal actions and pass.

**Comparisons** U uses uniform averaging. G uses a global attention key. L adds the previous shape, the policy average of available shapes and the availability/distance summary to the global key. G gets an equal-width fixed nonlinear expansion of its existing global features. A uses L's key and replaces explicit shape products with within-action functions. Use two seeds (17, 29), independently trained arms, same episodes and 4000 steps. Each episode contains 16 uniformly selected owners with three reference games and four positions from a disjoint query game. Use identical draws in every arm. Use the established identity CE ×10 logit scale and 0.1 move NLL. Choose checkpoints after every 1000 steps by development three-game identity CE plus 0.1 move NLL before scoring any test games. Reference support has equal game weights.

**Decision** Primary comparison L−G uses the equal-weight one/two/three-game rank score. Report U, A, comparison to within-game phase-stratified reference-value permutation, own minus wrong move log likelihood, plus the paired one-game minus three-game improvement. Use 5000 paired owner bootstrap draws. Require both seeds' L−G, L−U and L−permutation rank intervals above zero to attribute a robust gain to local retrieval. Report L−A separately for explicit product evidence. A positive gain in likelihood alone supports personalization. The pilot uses a fresh set of adapter players, with no inference about Public gains. A passing pilot warrants comparison with the frozen full fusion on candidate-only games.

**Checks and execution**

1. Test opponent history including pass, the board boundary, full legal normalization and invariance of a distribution to which query action will be scored. Exercise opposite conditionals with identical marginal choices and permutation constraints.
2. Record the sample, source hashes, seed rules and resource use before reading test outcomes. Reuse existing audited SGF replay and physical signatures. Keep action tensors in allocation memory. Source-check the results and note current full-fusion status independently.
3. Run a single-GPU batch including the tests, extract, train, report, and verify the report from saved scores. Retain small artifacts and the immutable input manifest. Native implementer and final independent review per executing-plans.
