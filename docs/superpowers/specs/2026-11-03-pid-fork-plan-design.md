### 3.2 三種結果與對應的線

- **A1 候選局與訓練集有重複（封閉集）**：只記錄（重複比例、`player_id` 是否一致），主線照常提交；要不要用這個事實要等主辦單位回覆，回覆前不開任何用訓練標籤認人的程式（PR #4 維持暫停）。
- **A2 無重複、開局分布一致、自我辨識接近參考值**：主線成立，走支線 B。
- **A3 無重複、但 A3(i) 或 A3(ii) 成立**：開局訊號在官方資料上變弱或候選庫刻意相近，支線 C 與支線 B 並行開啟。

Public LB 的第一次上傳是 A2／A3 的最終裁判：fusion 的 Public 分數對第 7 項自我辨識分數的落差，寫進 METHOD_NOTES 後才排支線的優先序。

### 3.3 為什麼第 7 項是關鍵

自我辨識只用候選庫自己的 100 局，不需要測試題的標籤，所以 11/04 當天就能算出「假設測試局和候選局同分布，這 400 個候選人有多好分」。它和 Public LB 一比就能把兩種失敗分開：自我辨識高、LB 低 → 測試局與候選局分布不同（不同時期、不同對手）；自我辨識本來就低 → 候選庫裡有難負例。
