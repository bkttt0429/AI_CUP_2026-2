# Conditional behavior mechanism pilot

User approved testing the discussed ToMnet-inspired, attention-based conditional policy. Implement a small, bounded experiment, not a production replacement. Existing rank and identification pipelines remain untouched.

Use the 100 calibration players and embedded 10-game SGFs in the existing choice manifest. Hash-sort players into 64 training, 16 validation and 20 test players; no player overlap, no fold 0, no official pool queries. These players have been used in earlier exploratory research: the test is held out from this model's training, not pristine project-level confirmation. Use the existing seven reference / three held-out roles for evaluation. Training episodes resample disjoint reference/query games from training players only.

Freeze KataGo humanv0. At 16 deterministic, uniformly spaced own moves per game, keep all 384 trunk channels for all 361 points plus a separate pass channel. Use complete simple-ko legality as provided by the existing board implementation (no superko claim). Preserve normalized base log-policy, played move, pre-move value, trunk mean, phase, color, policy entropy, and the last eight moves strictly before the query. Full action features allow the new model to learn its own projection. Reference observations contain state and chosen-minus-expected action features; query conditioning never receives its current action.

Train three small models, all sharing the same frozen inputs and training budget: background (no personal information), global (reference summary), contextual (same global summary plus attention from query context to reference states and choices). Context encoder: trunk mean + value/phase/color/entropy, 128 hidden / 64 output; causal eight-move GRU 32. Reference value encoder: residual 385 + chosen log-policy, 128 hidden / 64 output. Joint reference summary 64; attention keys/queries 64; learned action projection 64. Shared background and personal logit corrections are added to base policy then normalized over every legal action. All modules are shared across players; no learned ID lookup table.

Train action NLL plus 0.1 times candidate classification CE (query-game mean log-policy divided by fixed temperature 0.1). Episodes: 16 players, three reference games, eight reference positions/game, one different query game, four query positions. AdamW lr 0.001, weight decay 0.0001, 1200 steps, seeds 20261116 and 20261117. Validate at step 0 and every 200 steps; select lowest mean own-action validation NLL separately for each arm. Freeze choices before test; do not change the grid after reading test data.

Evaluation: all 20 test candidates, seven references, three query games/player. Report own-action NLL, true-versus-mean-wrong reference margin, per-game identification, and paired player-cluster bootstrap CIs with both training seeds kept together. Contextual versus background is the personalization check; contextual versus global and attention-value permutation (global summary held fixed) check the added context binding. Also evaluate removal of reference action values. No fusion or R1 efficacy claim. A mechanistic positive requires contextual-vs-background NLL improvement and correct-vs-wrong reference margin with CI lower bounds >0, and positive contextual-vs-global and contextual-vs-permuted gains in both seeds; otherwise state which requirement failed. Even a positive only licenses a larger independent-player pilot.

Before real-data training, verify an equal-marginal, different-context synthetic problem on unseen functions and unseen query samples. Unit checks cover legal masking/pass, reference permutation, action permutation, query-action leakage, strict prefix history, whole-game and whole-player separation, and frozen protocol/provenance.

Resource ceiling: one GPU at a time, at most 60 allocated GPU minutes for this pilot including failed jobs; cache <=5.5 GiB; leave >=8 GiB free on /work. Extract resumable per-game records into the dedicated run directory. Stop on missing/nonfinite data or budget violation. No automatic cleanup of other artifacts, submission, merge or publishing.
